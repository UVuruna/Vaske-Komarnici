# About Us

**Script:** [About Us (script)](../about_us.css)

## Purpose

Styles the "about the business" article section: centered layout, the
screen-types list, and the call-to-action block.

## Connections

### Uses

- none (pure styling)

### Used by

- Root `index.php` and [O Nama (folder)](../../o_nama/___o_nama.md) — loaded
  whenever [About Us](../../html/__about/about_us.md) is on the page
- [About Us](../../html/__about/about_us.md) — the markup this stylesheet
  targets

## Key Selectors

- `#about_us` — centered column layout, rounded corners
- `.cta` — the call-to-action button's centered wrapper
- Two breakpoints (750–1080px, ≤750px) that only adjust horizontal padding
